## 📌 About the Project

**EchoScript** is a browser-based Speech-to-Text Note Analyzer developed as part of a **Text & Speech Analysis** project.

The application converts spoken language into text using the browser's **Web Speech API** and analyzes the generated transcript to identify useful speech patterns.

It provides information such as word count, sentence count, filler words, repeated words, vocabulary diversity, and estimated speaking pace.

The application runs directly in the browser and does not require a custom backend server.

---

## 🎯 Objective

The main objective of EchoScript is to demonstrate how **speech recognition and text analysis** can be combined into a simple web application.

It can be useful for:

- 🎓 Students
- 🎤 Public speaking practice
- 🗣️ Speech practice
- 📝 Note taking
- 👨‍🏫 Presentation preparation
- 🔬 NLP learners
- 💻 Text & Speech Analysis projects

## ✨ Key Features

### 🎙️ Speech-to-Text

Converts spoken language into text using the browser's Web Speech API.

### 📝 Live Transcript

Displays recognized speech as a live transcript while the user is speaking.

### 🔢 Word Counter

Calculates the total number of words detected in the transcript.

### 📄 Sentence Counter

Counts the detected sentences in the transcript.

### 🗣️ Filler Word Detection

Detects commonly used filler words such as:

- Um
- Uh
- Erm
- Like
- Basically
- Actually
- Literally
- You know
- I mean

### 🔁 Repeated Word Detection

Identifies consecutive repeated words in the generated transcript.

### 📊 Vocabulary Diversity

Calculates the percentage of unique words compared with the total number of words.

### ⚡ Speaking Pace

Estimates speaking speed using **Words Per Minute (WPM)**.

### 💡 Speech Insight

Generates a simple insight based on the detected speech patterns.

### 📋 Copy Transcript

Allows users to copy the generated transcript.

### 🗑️ Clear Transcript

Clears the transcript and resets the analysis.
